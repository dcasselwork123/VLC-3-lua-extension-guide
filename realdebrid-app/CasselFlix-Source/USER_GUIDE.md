# Real Debrid Streamer - Simple Installation Guide

## 🚀 For Users (No Technical Knowledge Needed!)

### **One-Time Setup** (Do this once):

1. **Install Node.js**:
   - Go to: https://nodejs.org/
   - Download the LTS version (green button)
   - Run the installer
   - Click Next, Next, Next, Install
   - Restart your computer when done

2. **Download the app**:
   - Download `RealDebridStreamer-Source.zip`
   - Extract to a folder (e.g., `C:\Streamer\`)

3. **Build the app** (only need to do this once):
   - Open the extracted folder
   - Double-click `build-fixed.bat`
   - Wait 3-5 minutes
   - You'll see "BUILD COMPLETE!"

4. **Install**:
   - Go to the `dist-final` folder
   - Run `RealDebridStreamer-Setup.exe`
   - Follow the installer
   - Done!

---

## 🎬 Using the App

### **First Time Setup**:

1. Open "Real Debrid Streamer" from your Start Menu
2. Click the **Settings** tab
3. Enter your **Real Debrid API Key**:
   - Get it from: https://real-debrid.com/apitoken
   - Copy and paste the key
4. Enter your **TMDB API Key** (optional):
   - Get it from: https://www.themoviedb.org/settings/api
   - Use the first key shown ("API Key v3 auth")
5. Click **Save Settings**
6. Click **Test Connection** to verify

### **Streaming Movies**:

**Method 1: Browse**
1. Click **Browse** tab
2. See popular movies with posters
3. Click any movie card
4. Click **Stream**
5. VLC will open and start playing!

**Method 2: Search**
1. Click **Search** tab
2. Type a movie name
3. Click **Search**
4. Click **Stream** on any result

**Method 3: Direct Link**
1. Click **Home** tab
2. Paste a magnet link
3. Click **Stream**

## ❓ Troubleshooting

### "No torrents found"
- Try a different, more popular movie
- Some movies may not have torrents available
- Try adding the year (e.g., "Inception 2010")

### "Real Debrid error"
- Check your API key in Settings
- Make sure you have an active Real Debrid subscription
- Try clicking "Test Connection" in Settings

### VLC won't open
- Make sure VLC is installed: https://www.videolan.org/vlc/
- Install it to the default location

### App won't start
- Make sure you ran the installer
- Try running as Administrator
- Check Windows Defender isn't blocking it
